POPQ.

Scan. Order. Enjoy.

주문 순간의 불편을
끊김 없는 흐름으로.

팝업스토어·푸드트럭·플리마켓에서 QR을 스캔해 주문하고, 판매자는 실시간으로 접수·준비·완료 상태를 관리하는 고객 앱·판매자 앱·운영 웹 통합 플랫폼입니다.

01SCAN

MY CONTRIBUTION실시간 주문 · 결제 안정화 · 채팅 · 인증 · AI 준비시간 추천

고객과 판매자의 주문 경험을 연결하는 핵심 흐름을 담당했습니다.

01 / REALTIME ORDER

고객과 판매자의 상태를 동기화

Flutter 앱의 주문 이벤트 구독과 판매자 주문 상태 변경을 연결해 접수·준비·완료 상태가 실시간으로 반영되도록 구현했습니다.

WebSocket · STOMP · Flutter
02 / PAYMENT SAFETY

결제 실패에도 주문 흐름을 복구

결제 승인 상태 조회, 미확정 결제 저장과 앱 재실행 복구, 중복 승인 방지, 취소·환불 사유 이력을 구현했습니다.

Payment API · Recovery · Idempotency
03 / LIVE CHAT

주문 문의를 실시간 대화로

고객·판매자 앱 채팅과 백엔드 메시지 저장, 오래된 메시지 페이지네이션, 전송 실패 재시도 흐름을 구성했습니다.

WebSocket · Pagination · Retry UX
04 / AUTH & AI

세션 안정성과 운영 판단을 개선

JWT Refresh Token 자동 재발급과 STOMP 재연결을 적용하고, FastAPI 기반 AI 예상 준비시간 추천을 판매자 수정 흐름에 연결했습니다.

JWT · FastAPI · Spring Boot
